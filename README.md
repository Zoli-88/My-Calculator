<h1>Calculator Project</h1>
<img width="539" height="748" alt="Calculator-Screenshot" src="https://github.com/user-attachments/assets/d3a91256-883a-4425-9e2b-3908ded1269f" />
<p>This is a simple calculator I've built with HTML, CSS and JavaScript to practice functions, variables, state and DOM manipulation. It can perform basic mathematical operations like addition, substraction, multiplication, division and percentage.</p>
<p>It also has a sign toggle, AC (all clear) and backspace button.</p>
<p>The calculator only has basic styling, since the focus was on practicing algorithmic thinking, dealing with various states, variables, functions, event listeners and DOM manipulation using JavaScript. All in all, a great little exercise to practice some of JavaScript's features.</p>
